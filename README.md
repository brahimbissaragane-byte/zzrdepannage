# ZZR Dépannage — site public

Site : https://zzrdepannage.com/

## Changer les prix, le numéro ou le dépôt
1. Ouvre `index.html`, touche le crayon (Edit).
2. Cherche `const CONFIG` en haut du code.
3. Change le nombre (avec un point : `1.70`, pas `1,70`).
4. Touche **Commit changes**. Le site se met à jour en 1 à 2 minutes.

Si le site devient vide après une modification : ouvre **History** de `index.html` et remets la version d'avant.

## Fichiers
- `index.html` : le site (réglages dans `CONFIG`)
- L'image du haut est une illustration (carte + trajet) dessinée dans `index.html`
- `qr-affiche.png`, `qr-code.png` : QR code vers le site
- `og-image.jpg` : image de partage WhatsApp / Facebook
